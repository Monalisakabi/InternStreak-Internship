## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Monalisakabi/InternStreak-Internship.git
```

### 2. Open the project

Import the project into IntelliJ IDEA, Eclipse, or Spring Tool Suite.

### 3. Configure Java

Install a compatible JDK and configure your IDE.

### 4. Build the project

```bash
mvn clean install
```

Follow the instructions and configuration required by individual exercises.
