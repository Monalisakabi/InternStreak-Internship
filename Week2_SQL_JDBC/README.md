## How to Run

1. Start MySQL.
2. Execute the SQL files from the `sql` folder.
3. Configure the MySQL username and password in the Java files.
4. Reload Maven dependencies.
5. Run `JDBCConnection.java`.
6. Run `LibraryManagement.java`.
7. Run `EmployeeManagement.java`.
